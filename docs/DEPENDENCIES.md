# Dependency provenance

Airnode TypeScript and Solidity helper source is derived from the official API3 starter at commit `52933ae1fb9371446a927338473466c3d320e19a` (MIT), inspected 2026-10-31. Original license is in API3_STARTER_LICENSE. Request hashes are computed before fetching, raw signed data bytes are preserved. App package versions are exact and locked by package-lock.json. Solidity dependency revisions are pinned by foundry.lock.
